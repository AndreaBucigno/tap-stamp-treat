# Tap Stamp Treat

Avevo intenzione di creare un applicazione per dei locali /bar che genera delle carte virtuali per i clienti da tenere nel wallet e ogni volta che raggiungono una quota di 10 acquisti certificati da scansione del qr code il titolare decide cosa dare al cliente un omaggio/percentuale di sconto
